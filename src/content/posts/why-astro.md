## 缘起

想搭一个个人博客很久了，一直拖延。直到遇到了 Astro，发现原来静态站点可以这么简单。

## Astro 的特点

### 零 JavaScript 默认输出

默认情况下，Astro 不会给页面注入任何 JS。只有当我需要交互时才按需加载。这意味着：

- 页面加载飞快
- SEO 友好
- 服务器渲染开箱即用

### 多框架支持

你可以在同一个项目里混用 React、Vue、Svelte 组件。但我选择纯静态，只用 `.astro` 文件就足够了。

### Markdown 原生支持

写文章就是写 Markdown，自动转成 HTML。语法高亮、Frontmatter 配置都非常自然。

## 我的搭配

这个博客用的技术栈很简单：

- **Astro** — 静态站点生成
- **Tailwind CSS** — 样式方案
- **Vercel / GitHub Pages** — 部署

## 给同样想搭博客的你

1. 不用纠结选什么框架，选一个开始就行
2. 内容比技术栈重要
3. 先发布再完善
4. 这个博客就是最好的证明

希望你也拥有自己的小小角落。
