## 从哪里开始

很多人问我前端怎么学。说实话，我自己也是摸索过来的。分享一下我的路径，希望能帮到你。

## 第一阶段：三件套

不管学什么框架工具，这三是根基：

- **HTML** — 页面的骨架
- **CSS** — 页面的皮肤
- **JavaScript** — 页面的灵魂

建议按顺序学，不要着急跳框架。花一两个月打好基础，后面的路会好走很多。

## 第二阶段：工具链

基础打牢后，开始接触开发工具：

1. **Git** — 版本控制，让你的代码有"后悔药"
2. **VS Code** — 编辑器，插件生态丰富
3. **Node.js / npm** — 包管理和构建工具

## 第三阶段：框架

现代前端离不开框架。我推荐 **React** 或 **Vue** 二选一：

- React 生态大、工作机会多
- Vue 上手快、中文文档友好

我自己是先学了 Vue，后来补了 React。两个都会的话就业面更宽。

## 第四阶段：实战

- 做一两个完整的练手项目
- 把代码 push 到 GitHub
- 写博客记录学习过程（就像现在这样！）

## 最后

编程很难，但不是不可能。每天进步一点点，时间会给你答案。
